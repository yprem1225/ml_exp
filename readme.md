## 🚀 Installation and Execution

### Step 1: Install Python

Download Python from https://www.python.org/downloads/

Verify installation:

```powershell
python --version
```

### Step 2: Install Required Libraries

Open the VS Code terminal and run:

```powershell
python -m pip install pandas scikit-learn matplotlib
```

### Step 3: Run the Experiment

Make sure `svm.py` and `students.csv` are in the same project folder.

Execute:

```powershell
python svm.py
```

### Step 4: View the Output

The program displays:

- First five dataset records
- Model accuracy
- Confusion matrix
- Classification report
- Prediction for a new student
- Confusion matrix graph

### Step 5: Run Without Internet

After Python and all required libraries are installed, you can execute the experiment offline.

## 📦 Requirements

- Python 3
- Pandas
- Scikit-learn
- Matplotlib
- Visual Studio Code
- Git (for GitHub upload)
